# 🎥 MeetMate

### Real-Time Video Conferencing Web Application

MeetMate is a real-time video conferencing web application that allows users to connect with each other through video and audio communication directly from the browser.

The project was built to understand real-time communication, WebRTC, media devices, and full-stack web application deployment.

## 🧠 How It Works

MeetMate uses Socket.IO for real time signaling and WebRTC to establish real-time peer-to-peer audio and video communication between users.

1. User joins a meeting.
2. Browser requests camera and microphone permissions.
3. Local media streams are accessed using browser APIs.
4. A connection is established between participants.
5. Audio and video streams are exchanged in real time.
6. Users can communicate directly through the browser.
